# sesiones/

Handoffs entre sesiones de trabajo + prompts para continuar en nueva sesión + bitácora.

## Convención nombre archivo

- `HANDOFF_YYYY-MM-DD_TITULO_CORTO.md` — estado al cierre de sesión.
- `PLAN_*.md` — planes de ejecución multi-fase.
- `BITACORA_YYYY-MM.md` — bitácora mensual con entradas cortas por día.

## Cuándo crear handoff

- Sesión llega a 60%+ context window.
- Cambio de área (backend → frontend).
- Hito alcanzado (deploy, release, decisión grande).
- Cierre de día de trabajo.

## Estructura mínima handoff

1. Estado al cierre.
2. Decisiones cerradas en la sesión.
3. Prompt copy-paste para abrir nueva sesión.
4. Pendientes inmediatos.
5. Decisiones pendientes a resolver.
6. Archivos clave referenciados.
