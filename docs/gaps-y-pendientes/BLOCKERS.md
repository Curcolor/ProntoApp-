# Blockers activos

Bloqueos que requieren decisión humana o acción externa para desbloquear. Cuando el agente en modo `/goal` se topa con uno, debe documentar aquí y continuar con siguiente tarea (no insistir).

## Plantilla

```markdown
### [TIMESTAMP] — [TITULO]

- **Tarea bloqueada:** qué intentaba hacer.
- **Por qué bloquea:** error específico / decisión necesaria.
- **Acción requerida:** qué necesita el humano hacer/decidir.
- **Intentos hechos:** lista de approaches probados.
- **Workaround si existe:** cómo evita parar todo.
- **Severidad:** P0 (todo el plan se detiene) / P1 (esta fase se detiene) / P2 (esta feature se detiene).
```
